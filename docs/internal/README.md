# Internal working notes

Not part of the submission. These are the working notes the project was built
from and checked against, kept in the repository so that how it was built is
inspectable rather than asserted.

- `planning/` — the two briefs that directed the autonomous build sessions
  (Sept 5 and Sept 6). `docs/AI_USAGE.md` explains what they were for.
- `gauntlet/` — the review passes run against the finished repository:
  `CRITERIA.md` (the sponsor rules the project was scored against),
  `FACTS.md` (every claim the project is allowed to make, each pinned to a
  transaction hash or a command that was actually run), and the pass write-ups.

The gauntlet files enumerate the project's remaining gaps deliberately. Nothing
here supersedes `README.md`, `docs/SUBMISSION.md` or `docs/THREAT_MODEL.md`.
