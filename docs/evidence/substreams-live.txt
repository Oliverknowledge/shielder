Rust toolchain — which is why the artefact is committed.

has already cached and varies between runs. 'Received Blocks' is the

### 3. The honest result

'Completed successfully' with no flow rows is what this should print today.
The composition, the authentication and all five modules run live against a
Graph Market provider. There are no rows because ShieldVault.sol is deployed
on HyperEVM *testnet* (998) and The Graph indexes HyperEVM *mainnet* (999)
only — there is no testnet entry in its networks registry. The running
server reports the same thing at /api/health as
  substreamsAvailable: "no: The Graph indexes HyperEVM mainnet only"
and the app prints that sentence on its Behaviour screen. The addresses in
substreams.yaml move to the mainnet vault the moment it is deployed;
nothing else about this pipeline changes.
